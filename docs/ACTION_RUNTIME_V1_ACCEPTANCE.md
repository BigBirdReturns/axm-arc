# Action runtime v1 acceptance

This record separates the Arc authority claim from the later World receiver claim.

The Arc candidate is accepted only when the committed head passes typecheck, the complete Vitest estate, the production build, and the dedicated action tests. Before publication, the exact candidate tree passed `npm run typecheck`, `npm test` with 109 files and 861 tests, and `npm run build`. The committed-head CI remains the permanent referee.

The dedicated estate must prove that every one of the 48 shipped challenges compiles and clears through the same fixed-step kernel, that difficulty composition remains Arc-owned, that receipts replay exactly, that tampering is refused before campaign mutation, and that guided Workshop authoring produces schema-valid `axm.action@1` law.

This acceptance does not claim a finished third-person renderer, animation library, input surface, encounter art set, or constrained-device frame budget. Those are coordinated World receiver gates against the same action spec and receipt authority.
